📘 Many-to-Many Bidirectional Mapping (JPA + Hibernate)
🚀 Project Overview

This project demonstrates the implementation of a Many-to-Many Bidirectional Association using JPA (Java Persistence API) and Hibernate ORM.

It models a real-world relationship where multiple entities are associated with each other in both directions, ensuring proper synchronization and database integrity.

🧠 Concepts Covered
🔁 Many-to-Many Relationship
🔄 Bidirectional Mapping
🗂️ Join Table Handling
⚙️ Hibernate ORM Configuration
🧱 JPA Annotations
💾 Database Integration (MySQL)
🧹 CRUD Operations
⚠️ Exception Handling & Validations
🏗️ Tech Stack
☕ Java (Core + OOP)
🗃️ MySQL
🔗 JDBC
🧩 Hibernate ORM
📦 JPA (Jakarta Persistence)
🛠️ Eclipse IDE

🔗 Entity Relationship
📌 Example:
A Student can enroll in multiple Courses
A Course can have multiple Students

👉 This relationship is managed using a Join Table
